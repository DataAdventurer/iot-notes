Why are embedded systems designed for specific tasks rather than general-purpose computing?

In embedded systems it is more cost effective and efficient to run a machine with one chip, so called the brain of the system. General purpose computers are designed to run many different applications but embedded systems are designed for specific task with particular performance, power, and cost limitations.

1.1
Why have embedded systems become essential in modern electronic devices and industrial systems?

Embedded systems have become essential because small chip can do one job very well, such as monitoring data, controlling devices. This allows devices to work automatically and efficiently.

1.2
What characteristics differentiate embedded systems from general-purpose computers?

Desktop computer is designed to run many different programs, but an embedded system is built to perform well defined tasks in a well defined environment. Embedded systems also have functional characteristics and operational characteristics.

1.3
Why must embedded system design consider both hardware and software simultaneously?

In embedded system design the developer must consider hardware limitations and software logic at the same time. The system has limited memory and power. Application logic, performance, and security must work within those hardware constraints.

1.4
Why are microcontrollers considered the core component of most embedded systems?

Microcontrollers are the core component because they act as the brain of the system. They collect real time data from sensors and use that data to perform tasks according to the program stored in the chip.

1.5
Why do embedded systems use multiple types of memory such as RAM, ROM, Flash, and EEPROM?

Embedded systems use multiple types of memory because each type has a different role. Some memory stores the program code, some stores temporary data, and some stores permanent configuration data. Using different memory types is important for system performance, reliability, and cost.

1.6
Why must embedded software be optimized for efficiency and reliability?

Embedded software must be optimized for efficiency and reliability because embedded devices have limited resources. Efficient code uses less memory and processing power, and reliable software ensures the system works correctly in real time situations where timing and stability are very important.

1.7
Why are real-time operating systems (RTOS) important in time-critical embedded applications?

RTOS is important because it controls how tasks are scheduled and executed in system with time critical operations. It manages task priorities so important tasks can run first. There are different scheduling methods such as pre-emptive scheduling and non-pre-emptive scheduling and so on.
